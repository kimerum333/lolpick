# PandaScore 동기화 — v0.14.0

수집은 DB 트랜잭션 밖에서 수행하고 검증 후 대상 시즌→경기→회원 순서로 반영합니다.
provider writer advisory gate는 동시 공급자 팀 UPSERT의 역순 경쟁을 막습니다. 대상 외 시즌 행은 잠그지 않으며 사용자 배팅은 이 gate를 사용하지 않습니다.
자동 수집은 1시간 간격(3600초), 신선도 한도는 기본 4500초입니다. 실제 사용자가 돌려둔 자동 수집은 변경하지 않았습니다.

팀은 동일 공급자/외부 ID를 재사용합니다. 오래된 수집으로 최신 표시를 덮어쓰지 않습니다.
누락/null/빈 공급자 이름·약칭·로고는 기존 표시를 삭제하지 않습니다. 실제 삭제는 별도 명시적 관리 정책이 필요합니다.
과거 경기에도 최신 팀 표시를 사용합니다. 누락된 region/color/location도 보존합니다.

TBD 참가자와 시작 시각 미정은 NULL로 저장합니다. 확정되지 않았거나 공급자 상태가 not_started가 아니거나 오래된 경기는 배팅을 차단합니다.
배팅 뒤 참가자 변경·A/B 교체는 충돌로 처리합니다. 배팅 전 같은 참가자의 재정렬은 슬롯/점수 대응을 유지합니다.
확실한 승자·무승부·취소만 정산하며 winner 없는 finished를 무승부로 추정하지 않습니다.
정산 원장 불일치는 savepoint 롤백 후 settlement_blocked로 남기고 확정 결과는 수집 정정으로 덮어쓰지 않습니다.

CLI: python -m app.sync_pandascore --help, sync --help.
운영 --watch는 첫 오류에 종료하므로 감독 도구/타이머 상태는 실제 서버에서 확인합니다.
Linux 시간당 systemd 예시는 실패 실행 이후 다음 시간에 새 프로세스로 시도합니다. 실제 설치는 이번 작업에서 하지 않았습니다.

현재 검증은 가상 응답·SQLite·대체 공급자 호출입니다. 이번 환경의 네이티브 PostgreSQL·실계정 호출은 미검증입니다.
공급자 JSON 크기/시간/압축/중복 필드/숫자 경계 검사는 기존 회귀로 유지합니다.
실제 서비스나 라이엇 등 제3자에게 부하·대량/병렬 요청·제한 우회를 하지 않습니다.
