처음 연결할 때


공개 /health → /ready → /seasons로 연결과 실제 ID를 확인하세요. 회원 기능은 새 Google 로그인 → POST /auth/session → 시즌을 지정한 GET /auth/me → 응원·context·배팅·이력 순서로 확인합니다. session·logout은 JSON 본문을 보내지 않습니다.


선택 쿼리는 체크한 항목만 전송합니다. 시각 숫자는 UTC epoch 밀리초이며, 개인 응답 시각 문자열은 타임존 포함 ISO 8601입니다. 배팅·정산은 실제 포인트 및 상태를 바꾸므로 테스트 계정·테스트 데이터를 사용하세요.


시간 초과·중단·네트워크 오류는 거래 취소를 의미하지 않습니다. 쓰기 결과가 미확인일 때는 새 키로 반복하지 말고, 같은 계정·로그인 세션·주소·본문·키로 서버 결과를 확인하세요. 이전 계정의 미확인 요청을 새 계정 토큰으로 보내지 마세요.


CORS와 실행 방법
이 파일을 개발 프론트와 같은 origin에 올리거나, 백엔드가 정확한 테스트 origin을 허용해야 합니다. file://에서 차단된다면 개발용 HTTP 서버로 제공하세요. 운영 서버에 null origin이나 임의의 모든 origin을 허용하지 마세요.
서버는 Authorization·Content-Type·Idempotency-Key 요청 헤더와 OPTIONS preflight를 처리하고, X-Request-ID·Retry-After·X-Data-Stale·X-Data-Age-Seconds를 브라우저에 노출해야 해당 값을 확인할 수 있습니다. CORS·TLS·네트워크 실패는 브라우저에서 정확히 구분할 수 없으므로 서버 로그의 요청 ID도 함께 확인하세요.




외부 라이브러리·폰트·분석 도구를 사용하지 않습니다. 자동 호출·자동 POST 재시도·상시 폴링이 없습니다. 응답 내용은 HTML로 실행하지 않고 텍스트로 표시합니다. 기본 입력·형식 검사와 별도로 실제 권한·거래·동시성은 서버가 검증합니다.
