# LOLPICK 프론트엔드

가상 포인트로 LoL 경기 승리를 예측하고 이벤트별 응원 기록을 남기는 Vue 프론트엔드 프로토타입입니다.

## 실행

Node.js 24와 pnpm 11을 사용합니다.

```sh
pnpm install
pnpm dev
```

개발 서버가 출력하는 로컬 주소에서 확인합니다.

```sh
pnpm test    # 베팅, 포인트, 계약, 인장, 저장 데이터 검증
pnpm build   # TypeScript 검사와 프로덕션 빌드
pnpm preview # 빌드 결과 미리보기
```

## 구현 범위

- 경기: 이벤트·상태별 필터, 풀 비율·예상 배당, 팀 선택과 금액 입력, 포인트 차감, 경기 시작 시 신규 베팅 차단.
- 응원: 이벤트 첫 베팅 전 계약 체결, 진행 중 계약 팀 변경 금지, 상대 팀 베팅 시 인장 즉시 박탈. 이후 응원 베팅으로도 인장은 복구되지 않습니다.
- 랭킹: 2026 통합·Worlds·MSI 샘플 손익 랭킹. 내 미정산 베팅은 성적에 포함하지 않습니다.
- 프로필: 보유 포인트, 베팅 중 포인트, 이벤트별 베팅 기록, 응원·배신 횟수, 샘플 계정 초기화.
- 이용 가이드, 모바일 레이아웃, 키보드 접근 가능한 베팅 모달.

경기·일정·랭킹과 초기 지급 128,500P는 시연용 데이터입니다. 실제 공식 일정이나 확정된 포인트 지급 정책을 뜻하지 않습니다. 베팅과 계약은 `localStorage`의 `lolpick.demo.v1`에 저장됩니다. 샘플 일정은 체험을 시작한 시각을 기준으로 생성하며, 저장된 베팅은 새로고침 후에도 복원합니다.

추가 베팅 정책이 미정이므로 이번 버전은 경기당 한 번의 베팅만 지원합니다. 실제 회원 인증·API·실시간 서버 데이터·경기 결과 정산·출석 보상·대출·파산은 아직 구현하지 않았습니다. 샘플 경기 시작 후에는 정산 대기 상태가 유지됩니다. 프로필에서 체험을 초기화할 수 있습니다.

## 구조

- `src/domain/game.ts`: 샘플 데이터와 베팅·계약·인장 규칙. 백엔드 연결 시에도 서버에서 같은 규칙을 검증해야 합니다.
- `src/stores/game.ts`: Pinia 상태와 브라우저 저장.
- `src/views/`: 경기, 랭킹, 프로필, 이용 가이드 페이지.
- `src/components/`: 경기 카드, 팀 표시, 응원 계약, 베팅 모달.
- `src/router.ts`: 해시 기반 라우팅. 정적 호스팅에서도 페이지 새로고침을 지원합니다.
- `tests/game.test.mjs`: Node 내장 테스트 러너로 핵심 도메인 동작 검증.

서비스 규칙은 상위 디렉터리의 `docs/0.concept`를 참고합니다.
