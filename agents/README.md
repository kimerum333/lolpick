# Lolpick: AI 작업용 안내

Lolpick은 가상 포인트로 LoL 경기 승패를 예측하고, 이벤트별 베팅 성적과 응원 기록을 쌓는 서비스다. 포인트는 현금으로 환전하거나 사용자끼리 양도할 수 없다.

- **경기 베팅:** 경기 시작 전 한 팀에 베팅한다. 양 팀의 베팅 총액에 따라 예상 배당이 달라지고, 결과 확정 후 포인트를 정산한다.
- **이벤트 응원:** 이벤트마다 응원 팀과 계약할 수 있다. 그 팀의 상대에게 베팅하면 해당 이벤트의 응원 인장을 잃는다.
- **포인트 경제:** 가입·출석·이벤트 보상, 대출·상환·파산이 참여를 이어주는 장치다.
- **기록:** 랭킹과 프로필에서 베팅 성적과 응원 기록을 보여준다.

세부 규칙은 [`docs/0.concept`](../docs/0.concept)와 [`docs/1.requirements`](../docs/1.requirements)를 먼저 확인한다. 이 파일은 방향만 요약한다. 문서에 없는 동작은 확정된 요구사항으로 취급하지 않는다.
