# LOLPICK

가상 포인트로 LoL 경기 승리를 예측하고, 이벤트별 베팅 성적과 응원 기록을 쌓는 서비스입니다. 포인트는 현금으로 환전하거나 사용자끼리 양도할 수 없습니다.

## 서비스 컨셉트

- **경기 베팅:** 경기 시작 전에 한 팀의 승리에 포인트를 겁니다. 양 팀의 베팅 풀 비율로 배당이 결정되고, 결과 확정 후 승리 팀 베팅자에게 전체 풀을 지분대로 분배합니다.
- **이벤트 응원:** 이벤트별 응원 계약으로 팀 인장을 받습니다. 계약 후 이벤트 진행 중에는 팀을 바꿀 수 없으며, 상대 팀에 베팅하면 해당 이벤트의 인장을 영구적으로 잃습니다. 계약과 기록은 유지됩니다.
- **포인트 경제:** 가입·출석·이벤트 보상과 대출·상환·파산을 통해 참여를 이어가는 구조입니다.
- **랭킹과 프로필:** 이벤트별 베팅 성적과 응원 기록을 축적하고 비교합니다.

## 화면 실행

Node.js 24와 pnpm 11이 필요합니다.

```sh
git clone https://github.com/kimerum333/lolpick.git
cd lolpick/frontend
pnpm install
pnpm run dev
```

실행한 컴퓨터에서는 `http://localhost:5173`으로 접속합니다. 같은 네트워크의 다른 컴퓨터에서는 개발 서버가 출력하는 `Network` 주소를 사용합니다.

### 함께 확인할 흐름

1. 경기 화면에서 응원 팀을 선택하고 계약을 확정합니다.
2. 베팅 가능한 경기에서 승리 팀과 금액을 선택합니다.
3. 상대 팀 베팅 시 인장 박탈 안내와 실제 인장 상태 변화를 확인합니다.
4. 프로필에서 포인트 차감, 베팅 기록, 응원·배신 횟수를 확인합니다.
5. 랭킹에서 통합·이벤트별 샘플 성적을 비교합니다.

프로필의 **체험 다시 시작**으로 브라우저에 저장된 샘플 기록을 초기화할 수 있습니다.

## 현재 구현 상태

경기·랭킹·프로필·이용 가이드를 포함한 프론트엔드 프로토타입입니다. 경기 일정과 랭킹은 샘플이며, 베팅과 응원 계약은 브라우저에 저장됩니다.

백엔드에는 인증·서버 세션·경기 조회·응원·베팅·정산 API가 구현되어 있으며, 실행·검증·배포 구성은 [백엔드 README](backend/README.md)에 있습니다. 프론트엔드 프로토타입은 아직 이 API와 연결되지 않았습니다. 출석 보상·대출·파산과 시즌 전체 성적 랭킹 API는 미구현입니다. 프론트 실행 방법은 [프론트엔드 README](frontend/README.md)를 참고하세요.

## 소스 구성

- `backend/app/`: API와 운영 명령. 데모 데이터 생성기는 포함하지 않습니다.
- `backend/tests/`: 회귀 검사와 격리 DB용 가상 데이터. `fixtures/api-examples.json`은 API 문서 생성과 클라이언트 검사에도 사용합니다.
- `backend/docs/`, `backend/migrations/`, `backend/deploy/`: API 연결 자료, DB 이관, 서버 설정 예시.
- `frontend/`: 샘플 데이터로 동작하는 기존 화면. 실제 데이터 교체는 프론트 API 연결 단계에서 수행합니다.
- `docs/`: 서비스 기획과 요구사항. 구현 완료 목록과는 구분합니다.

소스 ZIP에는 Git 내부 데이터, 가상환경, 의존성 설치 폴더, 빌드 출력, 캐시, 운영 설정과 로그를 넣지 않습니다. 운영 배포에는 백엔드 패키지의 `runtime/` 또는 Docker 이미지를 사용하며, 테스트·문서·기획 자료는 웹 루트에 공개하지 않습니다.
