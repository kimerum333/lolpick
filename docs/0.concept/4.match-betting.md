# 경기 베팅

## 1. 경기
- 모든 베팅은 하나의 경기에 소속
- 경기는 하나의 이벤트에 소속
- 두 팀의 승패만 취급

## 2. 베팅 오픈
- 경기 시작 전까지 베팅 가능
- 한 경기에서는 한 팀만 선택 가능
- 같은 팀에는 추가 베팅 가능 여부 결정

## 3. 실시간 베팅 현황
Gen.G  ███████████████░░░░░  T1
        62%              38%

- 양 팀 총 베팅액 공개
- 예상 배당 실시간 변경

## 4. 배당
전체 베팅 풀을 승리팀 베팅자들이 지분대로 나눠가짐

Gen.G 8,000,000P
T1    2,000,000P

→ Gen.G 예상 배당 1.25x
→ T1 예상 배당 5.00x

## 5. 베팅 마감
경기 시작
→ 신규 베팅 차단
→ 최종 배당 확정

## 6. 결과와 정산
승리팀 확정
→ 패배팀 베팅액 포함 전체 풀 분배
→ 사용자 포인트 반영
→ 랭킹/프로필 통계 반영

## 7. 응원 계약과의 관계
응원팀 경기
├─ 응원팀 베팅 → 응원 베팅
└─ 상대팀 베팅 → 배신 + 인장 즉시 박탈
