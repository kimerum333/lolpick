- 각 경기는 하나의 이벤트에 소속된다.
- 랭킹은 선택한 연도와 이벤트에 소속된 경기의 베팅 결과만 집계한다.
- 이벤트가 통합으로 선택된 랭킹에서는 사용자의 현재 응원 인장을 표시한다.
- 특정 이벤트가 선택된 랭킹에서는 해당 이벤트에서 획득한 응원 인장을 표시한다.
- 응원 인장을 획득하지 못한 경우 별도의 팀 마크를 표시하지 않는다.

응원 계약
- 사용자는 각 이벤트마다 하나의 응원 팀을 선택할 수 있다.
- 응원 계약을 체결한 뒤 이벤트가 진행 중인 동안에는 해당 이벤트의 응원 팀을 변경할 수 없다. 베팅 참여 여부와 무관하게 적용한다.
- 응원 계약 팀이 출전한 경기에서 해당 팀에 베팅하면 응원 베팅으로 기록한다.
- 같은 경기에서 상대 팀에 베팅하면 내부적으로 배신 베팅으로 기록한다.
- 응원 계약을 체결하면 해당 팀의 이벤트 응원 인장을 즉시 획득한다.
- 배신 베팅이 확정되는 즉시 인장이 박탈되며, 해당 이벤트에서는 다시 획득할 수 없다. 응원 계약과 기록은 유지된다.
- 이벤트가 종료되면 응원 계약과 최종 인장 상태를 기록으로 보존한다. 다음 이벤트에서는 새로운 팀과 응원 계약을 맺을 수 있다.
- 통합 화면에서는 가장 최근 또는 현재 진행 중인 이벤트의 응원 인장을 현재 응원 인장으로 사용한다.
