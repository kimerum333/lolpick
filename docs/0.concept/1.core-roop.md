# 핵심 사용자 흐름

서비스의 주요 기능은 서로 다른 수명주기를 가진 몇 개의 흐름으로 구성된다.

경기 베팅은 개별 경기 단위로 반복되고, 응원 계약은 이벤트 단위로 유지된다. 포인트 경제는 특정 경기나 이벤트와 무관하게 계정 전체에서 지속된다.

---

## 1. 회원가입

사용자는 이메일 인증을 거쳐 계정을 생성하고 초기 포인트를 지급받는다.

```text
[이메일 / 비밀번호 / 닉네임 입력]
               ↓
         [이메일 인증]
               ↓
           [계정 생성]
               ↓
       [초기 포인트 지급]
               ↓
          [서비스 이용]
```

이메일 인증은 회원가입 화면을 유지한 상태에서 이메일로 전달된 숫자 인증 코드를 입력하는 방식으로 진행한다.

응원 팀은 회원가입 과정에서 선택하지 않는다.

---

## 2. 경기 베팅

각 경기는 독립적인 베팅 단위다.

사용자는 경기 시작 전까지 한 팀의 승리에 포인트를 베팅할 수 있으며, 다른 사용자들의 베팅에 따라 양 팀의 예상 배당이 계속 변한다.

```text
        [경기 공개]
             ↓
        [베팅 오픈]
             ↓
       [승리 팀 선택]
             ↓
        [포인트 베팅]
             ↓
   [베팅 총액 / 배당 변화]
             ↓
         [경기 시작]
             ↓
         [베팅 마감]
             ↓
        [경기 결과 확정]
             ↓
          [포인트 정산]
```

한 경기에서는 한 팀에만 베팅할 수 있다.

---

## 3. 이벤트 응원

응원은 개별 경기가 아니라 이벤트 단위로 결정한다.

사용자는 이벤트에서 응원할 팀을 선택하고, 해당 이벤트가 진행되는 동안 그 계약을 유지한다.

응원 계약을 체결한 뒤 이벤트가 진행 중인 동안에는 응원 팀을 변경할 수 없다. 베팅 참여 여부와 무관하게 적용한다. 이벤트 종료 후에는 해당 계약과 최종 인장 상태를 기록으로 보존하고, 다음 이벤트에서 새로운 팀을 선택할 수 있다.

```text
         [이벤트 시작]
               ↓
         [응원 팀 선택]
               ↓
         [응원 계약 확정]
               ↓
       [응원 인장 즉시 획득]
               ↓
       ┌──── 이벤트 진행 ────┐
       │                     │
       │  응원팀 경기 참여    │
       │        ↓            │
       │  응원 / 배신 베팅    │
       │        ↓            │
       │     기록 누적        │
       │                     │
       └─────────────────────┘
               ↓
          [이벤트 종료]
               ↓
       [최종 인장 상태 저장]
```

응원 계약 팀이 출전한 경기에서 해당 팀에 베팅하면 `응원 베팅`, 상대 팀에 베팅하면 `배신 베팅`으로 기록한다.

배신 베팅이 확정되는 즉시 응원 인장이 박탈되며, 해당 이벤트에서는 다시 획득할 수 없다. 응원 계약과 기록은 유지된다.

---

## 4. 포인트 경제

포인트는 서비스 전체에서 사용하는 가상 재화다.

베팅을 통해 증가하거나 감소하며, 서비스에서 제공하는 보상이나 대출을 통해 추가로 확보할 수 있다.

```text
          [포인트 획득]
               ↓
             [베팅]
               ↓
         [포인트 증감]
               ↓
       ┌──── 필요 시 ────┐
       │                 │
       ▼                 │
     [대출]              │
       ↓                 │
   [주간 상환]           │
    ↙       ↘            │
[상환 성공] [상환 실패]   │
    ↓          ↓         │
 [계속 이용]   [파산] ────┘
```

파산하면 부채를 포함한 경제 상태가 초기화되지만 계정 자체는 유지된다.

---

## 흐름 간 관계

각 흐름은 독립적인 주기를 가지지만 베팅을 중심으로 서로 연결된다.

```text
             이벤트 응원
                 │
                 │ 응원 / 배신 판정
                 ▼
회원 ───────→ 경기 베팅 ───────→ 랭킹 / 프로필
                 │
                 │ 포인트 증감
                 ▼
              포인트 경제
```

랭킹과 프로필은 별도의 반복 흐름이라기보다, 경기 베팅·응원·포인트 경제에서 축적된 결과를 사용자에게 보여주는 영역이다.
