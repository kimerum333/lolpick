# 이벤트 페이지 디자인

[이벤트 HTML](5.event.html)은 단일 이벤트의 날짜별 경기 목록이다. [기존 경기 HTML](3.match.html)은 변경하지 않는다. 화면 안에는 디자인 검토용 설명을 표시하지 않는다.

## 구성

- 상단 중앙: 이벤트 마크와 2026 Worlds.
- 타임라인: 10월 1일부터 11월 1일까지 하루 단위의 32개 위치. 시작일·종료일과 플레이인·스위스·8강·4강·결승 시작일을 표시한다.
- 기본 날짜: 브라우저의 현재 날짜를 한국 시간으로 계산한다. 이벤트 기간 밖이면 시작일 또는 종료일로 제한한다. 오늘 위치는 고정된 얇은 표시자로 남긴다. 오늘 버튼은 두지 않는다. 기간 밖에서는 오늘 표시자를 숨긴다.
- 날짜 선택: 슬라이더 드래그·트랙 클릭·좌우 방향키, 이전/다음 날짜 버튼과 단계 시작일 버튼. 방향키 한 번은 하루다. 첫날·마지막 날을 넘어가지 않는다.
- 시간 색상: 시작일부터 오늘까지는 어두운 금색으로 채운다. 오늘보다 과거를 선택하면 선택일–오늘 구간을 밝은 금색으로, 미래를 선택하면 오늘–선택일 구간을 푸른색으로 표시한다. 오늘 표시자는 선택일 이동과 관계없이 고정된다.
- 경기 목록: 선택 날짜의 카드를 한 줄씩 전체 폭으로 쌓는다. 왼쪽 절반은 팀 마크–VS–팀 마크와 비중 게이지, 오른쪽 절반은 대회 단계·형식·경기 상태·시작 예정 시각이다. 모바일에서도 좌우 구도를 유지한다.
- 카드 호버: 금색 외곽선. 카드 전체가 하나의 상세 페이지 링크이므로 상태 표시 부분에서도 상세 페이지로 이동한다.
- 경기 없는 날: 일정 없음 표시. 날짜 선택은 계속 가능하다.

## 상세 연결

[별도 상세 프리뷰](6.event-match.html)는 기존 경기 HTML을 읽어 선택 경기의 팀·포인트·이벤트 단계·날짜·상태를 적용한다. 기존 파일 자체를 수정하지 않는다. 베팅 가능 경기에서는 상세 페이지의 베팅 모달을 사용하고, 마감·진행·종료 상태에서는 베팅을 막는다. 상세 페이지를 모달로 띄우지 않는다.

## 데이터와 범위

대회 마크는 직접 만든 임시 SVG이고, 일정과 단계 날짜·참가 팀·점수·포인트는 디자인용 가상 데이터다. 공식 2026 Worlds 일정이나 결과를 나타내지 않는다. 고정 일정에 브라우저의 현재 시간을 비교해 베팅 가능·베팅 종료·진행 중·종료 표현을 보여준다. 베팅은 상세 페이지 메모리 안에서만 반영하며 서버나 이벤트 목록에 저장되지 않는다.

## 확인

날짜 기본 선택, 방향키의 하루 이동, 시작·종료 경계, 단계 이동, 경기 없는 날짜, 상태 표현과 카드 링크, 320–1440px 레이아웃을 브라우저에서 확인한다.
