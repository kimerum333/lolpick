# 디자인 컨셉트

상태: 기본 방향은 다크 배경·금색 브랜드 포인트·팀 테마 게이지로 정했다. 구체적인 색상값과 레이아웃은 시안에서 검토한다. 서비스 규칙의 기준은 [기존 컨셉트 문서](../0.concept/0.intro.md)다.

## 1. 중심 아이디어

**경기를 보면서 옆에 켜두는 예측 보드.**

LoL 팬이 경기 전에 선택하고, 경기 중에 내 선택을 확인하고, 경기 후에 성적과 응원 기록을 돌아보는 공간으로 만든다.

첫 화면에서 다음 세 가지를 쉽게 읽을 수 있어야 한다.

- 어떤 경기에 지금 참여할 수 있는가?
- 사람들이 어느 팀을 선택했고 예상 배당은 얼마인가?
- 나는 어느 팀을 응원하고, 어디에 얼마나 베팅했는가?

서비스의 인상은 **선명한 경기 정보, 선택하는 재미, 쌓이는 팬의 기록**으로 잡는다. 경기 자체가 시각적 중심이 되고, LOLpick의 브랜드는 탐색과 행동을 연결한다.

## 2. 화면을 구성하는 원칙

| 원칙 | 화면에서의 적용 |
| --- | --- |
| 경기가 먼저 보인다 | 경기 목록과 참여 가능 상태를 상단에 배치한다. 소개 문구와 이벤트 장식은 짧게 사용한다. |
| 양 팀을 같은 조건으로 비교한다 | 로고·이름·베팅 풀·배당에 같은 공간과 글자 크기를 준다. 내 선택은 테두리와 선택 표시로 추가한다. |
| 내 선택이 남는다 | 베팅 후에는 선택 팀·금액·정산 상태를 경기 목록에서도 확인할 수 있게 한다. |
| 응원과 예측의 관계를 드러낸다 | 응원 인장과 계약 팀을 구분하고, 상대 팀 베팅의 결과를 확정 전에 설명한다. |
| 숫자를 읽기 쉽다 | 배당, 포인트, 손익의 단위와 정렬을 통일한다. 선택한 기간과 이벤트를 통계 가까이에 표시한다. |

## 3. 선택한 시각적 방향

**다크한 경기 보드에 금색 브랜드 포인트, 팀 색상으로 나뉜 베팅 게이지.**

사용자의 방향에 따라 다크 모드를 기본 디자인으로 잡는다. LoL을 연상시키는 금색은 브랜드와 중요한 행동에 절제해 사용한다. 각 경기에서는 출전 팀의 테마 색이 양 팀 베팅 비율을 나타낸다.

| 역할 | 적용 방향 |
| --- | --- |
| 다크 배경 | 검정에 가까운 남색 바탕과 조금 밝은 카드 표면으로 경기와 기록을 묶는다. |
| 금색 | LOLpick 로고의 포인트, 주요 확정 버튼, 응원 인장의 프레임 등 제한된 곳에 사용한다. |
| 팀 색상 | 경기 팀 표시와 양 팀 베팅 게이지에 적용한다. 계약 팀 색상은 응원 영역에도 연결한다. |
| 상태와 선택 | 텍스트·아이콘·테두리로 별도 표현한다. 게이지의 팀 색상만으로 승리·손실·내 선택을 뜻하지 않는다. |

전체 분위기는 어두운 e스포츠 경기 보드로 잡고, 팬의 정체성은 팀 색과 인장으로 드러낸다. 금색은 작은 강조부터 적용하고, 화면 전체를 금색 선이나 장식으로 채우지 않는다.

밝은 테마는 이번 첫 시안의 범위에서 제외한다. 다크 테마에서 글자·숫자·팀 색상이 충분히 구분되는지 먼저 확인한다.

## 4. 현재 프로토타입에서 발전시킬 부분

- 큰 소개 제목과 이벤트 배너가 차지하는 높이를 줄여 첫 화면에 경기 정보를 더 보여준다.
- 경기 카드에서 팀, 시작 시각, 예상 배당을 더 크게 읽을 수 있게 한다. 참여율과 총 베팅액은 그 다음 순서다.
- 데스크톱의 내 포인트·응원 계약 영역은 유지하되, 모바일에서는 경기 목록 앞에 짧게 요약한다.
- 경기 종료, 베팅 마감, 정산 대기를 서로 다른 상태로 보여준다.
- 랭킹 상위 세 명의 장식보다 비교할 수 있는 표와 내 위치를 우선한다.
- 작은 영문 장식 문구는 줄이고 한국어 제목·상태·버튼을 중심으로 구성한다.

## 5. 다음에 함께 결정할 것

1. 경기 탐색 밀도: 큰 카드 두 개씩 또는 간결한 행 목록 중 어느 방식이 편한가?
2. 응원 인장: 팀 로고 중심인가, 별도의 이벤트 기념 인장 형태인가?

이 방향으로 경기 화면의 데스크톱·모바일 시안을 만들고, 같은 규칙으로 베팅 화면과 랭킹·프로필을 확장한다.
