# 시각 표현 초안

상태: 다크 배경·금색 브랜드 포인트·팀 테마 게이지를 기본 방향으로 정했다. 아래 색상값·폰트·크기는 시안용 초안이며 실제 화면에서 확인한 뒤 확정한다.

## 1. 형태와 밀도

- 팀 로고, 팀 이름, 배당 숫자가 화면의 시각적 중심이다.
- 카드와 표는 정렬과 얇은 구분선으로 묶고, 큰 그림자와 반복 장식은 줄인다.
- 로고·상태·배당·내 선택을 같은 위치에 반복해 여러 경기를 빠르게 비교하게 한다.
- 버튼과 입력은 명확한 경계를 갖는다. 선택 팀에는 테두리와 체크 표시를 함께 쓴다.
- 경기 관전 중에도 편하게 읽을 수 있도록 작은 설명을 과하게 줄이지 않는다.

## 2. 다크 배경과 금색 브랜드 포인트

| 역할 | 시안용 색상 | 적용 |
| --- | --- | --- |
| 전체 배경 | `#0B1018` | 페이지 전체 바탕 |
| 카드·표면 | `#141D29` | 경기 카드, 기록 표, 계정 영역 |
| 위에 뜨는 표면 | `#1D2938` | 베팅 모달과 메뉴 |
| 구분선 | `#324154` | 카드 경계와 표의 행 구분 |
| 주요 글자 | `#F2F5FA` | 제목, 팀 이름, 주요 숫자 |
| 보조 글자 | `#A8B4C5` | 시작 시각, 단위, 상태 설명 |
| 브랜드 금색 | `#C8AA6E` | 로고 포인트, 주요 행동, 인장 프레임 |
| 금색 버튼의 글자 | `#10151F` | 베팅·계약 확정 버튼 |

금색은 사용자가 제안한 LoL의 인상을 연결하는 브랜드 포인트다. 위 색상값은 LOLpick의 시안용 제안이며 공식 LoL 디자인 규격을 뜻하지 않는다.

금색의 사용 순서는 주요 확정 행동 → 로고의 작은 포인트 → 인장 프레임이다. 모든 숫자와 카드 테두리를 금색으로 강조하지 않는다. 게이지에는 각 팀의 색상을 사용한다.

### 팀 게이지

- 좌측 팀과 우측 팀의 베팅 풀 비율을 각 팀의 테마 색으로 표시한다. 카드마다 팀과 게이지의 좌우 순서를 일치시킨다.
- 게이지 양 끝에 팀명·비율을 표시하고, 예상 배당은 각 팀 쪽에 별도 숫자로 배치한다.
- 두 팀 영역 사이에 간격 또는 구분선을 둔다. 비율이 작은 팀도 수치를 통해 읽을 수 있게 한다.
- 같은 색 계열의 대진은 팀명·로고·좌우 위치로 식별하고, 필요하면 한쪽에 패턴이나 밝기 차이를 적용한다.
- 내 선택은 체크·테두리·`내 베팅` 표시로 표현한다. 선택 후에도 게이지는 양 팀 테마 색을 유지한다.
- 게이지는 베팅된 포인트 비율을 뜻한다. 실제 승리 확률이나 경기 스코어로 오해하지 않도록 `베팅 비율`을 표시한다.
- 팀 색상은 공식 자산을 확보한 뒤 확인한다. 현재 프로토타입의 색상은 샘플이며, 다크 배경에서 구분되지 않으면 로고의 원색을 유지하면서 게이지용 밝기를 조정한다.

예시 구조: `GEN · 62% [GEN 색상 ━━━━━ | ━━━ T1 색상] 38% · T1`. 게이지 아래에는 `예상 1.61×`와 `예상 2.65×`를 각 팀 쪽에 표시한다. 숫자는 설명용 샘플이다.

### 상태 색상

진행 중, 마감, 성공, 오류, 인장 박탈은 팀 색상·브랜드 금색과 별도의 의미를 갖는다. 색상과 함께 텍스트·아이콘을 붙인다. 빨간색 팀을 선택했다고 오류나 손실로 읽히지 않도록 팀 영역과 상태 안내의 위치를 구분한다.

후보 색상은 실제 버튼·입력·표에 적용한 뒤 글자 대비와 상태 간 구분을 확인한다. 특히 금색 버튼에는 진한 글자를 사용하고, 중요 상태를 낮은 대비의 회색으로 숨기지 않는다.

## 3. 글자와 숫자

- 한국어 제목·설명을 중심으로 한다. 영문은 브랜드·팀 이름·공식 이벤트 이름에 사용한다.
- 한글 산세리프 계열을 기준으로 하고 폰트 선택과 배포 방식은 별도 확정한다. 현재 시스템 폰트도 비교 대상으로 둔다.
- 본문은 14–16px, 주요 배당은 24–32px부터 시도한다. 모바일에서도 중요한 상태 설명을 읽을 수 있게 한다.
- 포인트와 성적 숫자는 자릿수가 바뀌어도 정렬이 유지되게 한다.
- 형식 예시: `5,000 P`, `2.65×`, `+33,000 P`, `61.2%`. 손익의 부호를 색상과 함께 표시한다.
- 전체 베팅 풀은 목록에서 축약할 수 있지만 입력 금액·내 베팅·수령액은 정확한 숫자로 표시한다.

## 4. 팀과 인장

팀 표시와 응원 인장은 역할을 구분한다. 경기의 팀 표시는 출전 팀의 식별이고, 사용자 옆의 인장은 이벤트 응원 상태다.

현재 프로토타입의 이니셜 방패는 임시 표현이다. 실제 로고 자산과 출처를 확보한 뒤 교체한다. 인장은 팀 로고 중심과 이벤트명을 결합한 기념 인장 두 안을 비교한다. 목록에서는 작은 식별 표시로, 프로필에서는 이벤트와 상태를 함께 읽는 기록으로 사용한다.

## 5. 움직임과 문구

선택·완료·포인트 변경을 짧게 알려준다. 경기 목록과 배당에는 지속적인 점멸이나 과한 움직임을 사용하지 않는다. 베팅 제출과 성공은 중복되지 않는 한 흐름으로 보여준다.

버튼은 행동을 구체적으로 설명한다. `베팅하기`, `응원 계약 확정`, `베팅 기록 보기`를 사용하고, 인장 박탈·마감·오류에는 다음 상태를 이해할 수 있는 문구를 붙인다.

## 6. 첫 시안의 비교 범위

같은 경기 데이터와 상태로 다음 화면을 비교한다.

1. 경기 목록: 데스크톱과 모바일, 다크 배경·금색 포인트·팀 테마 게이지 적용.
2. 경기 표시: 카드형과 행 목록형.
3. 베팅: 팀 미선택·선택·상대 팀 경고·완료 상태.
4. 응원: 계약 전·인장 보유·박탈 상태.

시안 평가 기준은 첫 화면에서 참여할 경기를 찾을 수 있는지, 양 팀 배당을 쉽게 비교하는지, 내 선택과 응원 상태를 오해하지 않는지다.
