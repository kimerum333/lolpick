# 탑바와 화면 결합

- [탑바 단독](8.topbar.html)
- [기존 화면과 결합](9.app.html)
- [로그인 전 결합 화면](9.app.html?auth=guest)

왼쪽에는 LOLpick 로고와 경기일정·랭킹·마이페이지 메뉴를 둔다. 현재 메뉴는 금색 글자와 짧은 밑줄로 표시한다. 오른쪽에는 로그인 버튼 또는 닉네임·보유 포인트·응원 인장과 계정 메뉴가 나타난다.

데스크톱에서는 한 줄, 좁은 화면에서는 로고와 계정 아래에 메뉴를 둔다. 페이지를 스크롤해도 탑바가 유지된다.

## 기존 화면 결합

9.app.html이 8.topbar.html의 탑바를 가져오고, 기존 이벤트 선택·이벤트 상세·경기 상세 HTML은 같은 출처의 iframe으로 연결한다. 본문 높이에 맞춰 iframe을 조절한다. 기존 HTML 파일은 수정하지 않는다.

로고와 경기일정은 이벤트 목록으로 연결한다. 이벤트와 경기를 열어도 탑바가 남는다. 랭킹은 메뉴 연결을 확인하기 위한 간단한 화면이다. 마이페이지는 10.profile.html의 레이아웃으로 연결한다.

로그인과 로그아웃은 URL의 auth=user/guest에 따른 디자인 상태 전환이며 실제 인증과 연결되지 않는다. 계정·포인트·랭킹은 고정 데이터이고 경기 상세의 베팅 상태와 공유하지 않는다.

## 확인

320·390·768·1440px에서 가로 넘침 없이 메뉴를 표시한다. 로그인 전후 표시, 계정 메뉴의 Escape 닫기, 메뉴 이동과 이벤트 진입 후 탑바 유지 동작을 브라우저에서 확인했다.
