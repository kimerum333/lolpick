# 로컬 시안용 전류 에셋

출처: [Electric VFX Pack — Animated 2D Effects / Dolkyns](https://dolkyns.itch.io/electric-vfx-pack).

경기 시안 03은 `Electric_Discharge`의 Yellow·Red 가로 스프라이트시트를 사용한다. 원본을 수정하지 않고 CSS로 재생·회전·마스크 처리한다. 각 시트는 4096×256px이며, 256×256px 16프레임을 24fps로 재생한다.

제작자 라이선스는 프로젝트 내 사용·수정·프로젝트 일부로 배포를 허용하고 독립 에셋 재배포와 재사용 템플릿 포함을 제한한다. 원본 시트와 동봉 문서는 `dolkyns/`에 로컬로 설치하고 Git 추적에서 제외한다. 협업자는 제작자 페이지에서 팩을 직접 받은 후 아래 경로에 배치한다.

| 팩 내부 경로 | 시안의 로컬 경로 |
| --- | --- |
| `Electric_Discharge/Yellow/Spritesheets/Spritesheet Strip.png` | `dolkyns/discharge-yellow.png` |
| `Electric_Discharge/Red/Spritesheets/Spritesheet Strip.png` | `dolkyns/discharge-red.png` |
| `LICENSE.txt` | `dolkyns/LICENSE.txt` |
| `README.txt` | `dolkyns/README.txt` |

에셋이 없는 상태에서도 경기 보드와 베팅 모달은 동작하며, 접점에는 기본 빛 번짐만 표시된다. 제품에 포함해 공개 배포할 때는 받은 라이선스 전문에 맞춰 에셋을 패키징한다.
