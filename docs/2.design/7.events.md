# 연도별 이벤트 타임라인

[HTML](7.events.html)은 이벤트 선택 화면이다. 기존 경기 상세와 개별 이벤트 HTML은 수정하지 않는다.

## 시간축

- 오른쪽 끝의 세로축: 2026 → 2025 → 2024, 위가 최신 연도.
- 각 연도에서 왼쪽으로 뻗는 가로축: 왼쪽 1월 → 오른쪽 12월. 월 눈금은 실제 달력의 일수에 비례해 배치한다.
- 리그: 가로축 위쪽. LCK 카드는 시작일부터 종료일까지의 기간만큼 길게 표시한다.
- 국제대회: 가로축 아래쪽. 기간 자체는 축 아래의 짧은 선으로 표시하고, 읽을 수 있는 최소 폭의 카드를 기간 중앙에 배치한다.
- 올해와 오늘: 오른쪽 연도 표식과 오늘 위치의 세로선을 금색으로 강조한다. 오늘은 한국 시간 기준이다.
- 모바일: 시간축을 압축하지 않고 가로 스크롤로 제공한다. 오른쪽 연도축은 화면 오른쪽에 고정되고, 최초에는 최신 월이 있는 오른쪽 부분을 보여준다.

## 연결과 데이터

2026 Worlds 카드에서 기존 [이벤트 페이지](5.event.html)로 이동한다. 다른 대회는 기간과 위치를 보여주는 정보 카드다. 대회 이름과 일정·기간·상태는 디자인용 가상 데이터이며 공식 일정이 아니다. 로고는 임시 SVG와 타이포그래피다. HTML 안에는 디자인 설명을 넣지 않는다.

미리보기: `http://192.168.0.3:5174/7.events.html`.
