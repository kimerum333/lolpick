# 에너지 게이지와 충돌 이펙트 조사

조사일: 2026-10-06. 현재 흐르는 게이지는 유지하고, 접점의 어색한 불꽃을 개선하기 위한 자료다. 조사 후 Dolkyns 팩을 무료로 받아 라이선스·파일 정보를 확인하고 시안 03에 적용했다. 나머지 후보는 제작자 설명을 확인한 상태이며 실제 적용 검증은 하지 않았다. 가격은 조사 시점의 표시다.

## 1. 현재 시안의 문제와 목표

사용자 피드백: 게이지가 흐르는 움직임은 좋지만 접점의 불꽃 연출이 어색하다.

현재 CSS 이펙트는 짧은 직선 입자가 정해진 방향으로 반복되고, 전류 모양이 같은 형태로 회전한다. 제작 관점의 진단으로는 불꽃의 형태 변화와 압력이 빠져 있어 장식이 반복되는 느낌을 준다. 목표는 **양쪽 에너지가 접점으로 몰리며 작은 범위에서 불규칙하게 부딪히는 것**이다.

게이지의 비율·숫자·버튼은 읽기 쉬운 위치를 유지한다. 충돌 연출의 크기를 늘려 정보 영역을 가리지 않는다.

## 2. 제작 방식 참고

[Stylized Energy Beam 제작자 분해 설명](https://realtimevfx.com/t/breakdown-stylized-energy-beam/21866)은 흐르는 텍스처를 적용한 빔과 중심부·입자·폭발을 여러 요소로 나누고, 시간에 맞춰 조합하는 과정을 보여준다. Unity 제작 예제이므로 웹 코드로 바로 붙이는 자료는 아니지만, 시각적 구성 원리를 참고할 수 있다.

[Pulse Cannon 제작자 분해 설명](https://realtimevfx.com/t/step-by-step-vfx-breakdown-pulse-cannon-effect/3161)은 서로 다른 투명도의 빔 텍스처, 빛, 전류, 노이즈 등의 층을 분리해 설명한다. 이를 바탕으로 LOLpick에서도 흐름과 충돌의 형태·속도를 따로 조절하는 방향을 제안한다.

### 방식 비교

| 방식 | 구현 | LOLpick에서 검토할 점 |
| --- | --- | --- |
| CSS + 애니메이션 스프라이트시트 | 투명 PNG의 프레임을 `steps()`로 재생하고 접점에 배치 | 접점 한 개를 바꾸는 첫 실험으로 적합. 규칙적인 격자와 프레임 크기·루프 정보를 확인해야 한다. |
| Canvas 2D + 프레임·입자 | 프레임별 이미지를 그리고 위치·속도·수명·투명도를 달리한 입자를 겹침 | 방향성과 불규칙한 움직임을 조절하기 좋음. 고해상도 모바일에서 그리는 영역과 입자 수를 제한한다. |
| PixiJS + 스프라이트·필터 | 애니메이션 이미지, 색상 조정, 밝게 합성, 노이즈 기반 변형을 조합 | 연출이 여러 개로 늘어나거나 색상·형태를 실시간으로 바꿀 때 검토. 라이브러리와 GPU 처리 영역이 추가된다. |
| WebGL 셰이더 | 시간에 따라 흐르는 노이즈로 빔과 접점을 직접 생성 | 독특한 형태를 만들 수 있으나 제작·조정 비용이 큼. 첫 시안은 작은 스프라이트 실험부터 시작한다. |

[PixiJS 공식 필터 문서](https://pixijs.com/8.x/guides/components/filters)는 텍스처를 이용한 변형과 혼합 효과를 설명한다. [장면 객체 문서](https://pixijs.com/8.x/guides/components/scene-objects)는 색상 조정과 필터의 GPU 처리, 과도한 필터 사용의 비용을 설명한다. 실제 사용 API는 도입 시 선택한 버전에 맞춰 확인한다.

스프라이트시트는 애니메이션 여러 프레임을 이미지 하나에 배열한 파일이다. 먼저 프리뷰로 원하는 움직임인지 고르고, 프레임 크기·개수·재생 속도·투명 배경·루프 여부를 확인한다. 격자가 일정하지 않은 시트는 메타데이터를 읽는 렌더러가 필요할 수 있다.

## 3. 에셋 후보

### CartoonCoffee · 2D Lightning & Electricity VFX

- [스프라이트시트 제품 페이지](https://cartooncoffee.itch.io/lightning-spritesheets)
- [PNG 프레임 제품 페이지](https://cartooncoffee.itch.io/lightning-video)
- 조사 시점 각각 US$24.99. HD 전기 이펙트를 프레임 또는 시트로 제공한다.
- 이 팩에는 빨강·흰색 버전이 포함되지 않는다는 안내가 있다. T1 빨강과 GEN 금색으로 변경한 결과는 별도로 확인해야 한다.
- 부드러운 게임 이펙트 방향의 우선 프리뷰 후보다. 실제로 지속 충돌에 맞는 루프가 있는지는 프리뷰와 파일 정보를 확인해야 한다.
- 개인·상업 프로젝트 사용과 프로젝트 목적 수정은 허용하되, 파일의 재배포·공유에는 제작자 제한이 있다. 공개 저장소에 원본을 넣기 전 배포 범위를 확인한다.

### Dolkyns · Electric VFX Pack

- [제작자 제품 페이지](https://dolkyns.itch.io/electric-vfx-pack)
- 무료로 받을 수 있는 자율 가격 방식. 256×256 투명 PNG 프레임, 격자·가로 시트, GIF 프리뷰 제공.
- `Electric Discharge`는 16프레임의 끊김 없는 루프라고 명시한다. 지속 접점의 첫 실험 후보다.
- 다른 번개·충격파 등은 단발 효과다. 반복하면 끝에서 사라지는 모습이 튈 수 있으므로 루프와 단발의 쓰임을 구분한다.
- 개인·상업 사용과 수정 허용, 독립 에셋 형태의 재배포·재판매 금지. 품질과 팀별 색상 적합성은 실제 적용 전 확인한다.

### Kenney · Particle Pack

- [제작자 다운로드 페이지](https://kenney.nl/assets/particle-pack)
- 무료, CC0. 512×512 크기, 80개 파일의 2D VFX 소재.
- 직접 입자를 만들 때 쓸 텍스처 후보다. 이것만 가져온다고 완성된 에너지 충돌 애니메이션이 생기는 것은 아니다.
- 공개 저장소에 실험 재료를 포함하기 쉬운 후보. 입자의 이동·수명·발생 빈도는 직접 설계한다.

### ARCLIGHT · Energy & Arcane VFX

- [제작자 제품 페이지](https://godboyhappy.itch.io/arclight-energy-arcane-vfx)
- PNG 스프라이트시트 형태의 빔·전류·충격파 팩. 완전 루프와 가로로 반복 가능한 빔을 제공한다고 설명한다.
- 빔까지 교체할 때 검토할 후보다. 현재 좋다는 피드백을 받은 CSS 게이지를 먼저 유지하고, 접점에 맞는 효과부터 살펴본다.
- 상업 사용·출처 표기 불필요 안내가 있으나 원본 파일을 에셋 팩으로 재판매하는 것은 금지한다. 저장소 배포 전 전체 라이선스를 확인한다.

Unity Prefab이나 Unreal Niagara 전용 패키지를 고르면 웹에 직접 넣을 수 없으므로, 첫 후보는 **투명 PNG 프레임 또는 스프라이트시트**로 좁힌다.

## 4. 다음 실험 제안

**기존 CSS 게이지 + 접점의 짧은 전류 루프 + 약한 빛 번짐**으로 첫 교체안을 만든다.

1. 후보 프리뷰에서 지속 루프가 자연스러운지 확인한다. 자율 가격의 Dolkyns 루프와 CartoonCoffee 제품 프리뷰를 먼저 비교한다.
2. 접점 한 곳에 적용한다. 중심 위치는 기존 `--left-share`로 유지한다.
3. 금색·빨간색 게이지와 충돌 이미지의 색이 연결되는지 확인한다. 중립적인 밝은 코어와 팀 색상의 주변 빛도 비교한다.
4. 기본 상태는 작게 유지하고, 실제 풀 변화가 생길 때만 짧은 추가 버스트를 주는 안을 검토한다.
5. 모바일 크기, 이미지 용량, 반복 종료 지점, 움직임 줄이기 상태를 확인한다.

처음부터 화면 전체에 물리 시뮬레이션이나 여러 종류의 셰이더를 추가할 필요는 없다. 핵심은 접점에 맞는 애니메이션의 형태와 재생 리듬을 고르는 것이다.

## 5. 검색어

- `stylized energy beam breakdown`
- `beam clash impact loop sprite sheet`
- `electric discharge seamless loop transparent PNG`
- `hand drawn lightning VFX spritesheet`

검색처는 에셋 구매·프리뷰용 itch.io의 제작자 페이지, 무료 소재용 Kenney, 제작 과정용 Real Time VFX, 웹 렌더링 구현용 PixiJS 공식 문서로 나눠 활용한다.

## 적용 결과

Dolkyns의 Electric Discharge Yellow·Red 루프를 [경기 시안 03](3.match.md)에 적용했다. 흐르는 CSS 빔은 유지하고 접점만 교체했다. 원본 시트는 로컬 설치하며, [설치·라이선스 안내](assets/README.md)를 함께 기록했다.

후속 피드백에서 전류가 길고 장식적으로 보인다는 의견이 있어 시안 04에서는 불꽃·전류를 제거하고 짧은 세력 바를 채택했다. 현재 HTML은 외부 에셋을 사용하지 않는다. 이 조사는 시안 03의 실험 기록으로 보존한다.
